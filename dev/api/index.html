API reference

The functions below operate on prepared JuChrom data or an open explorer session. For interactive workflows, start with the manual.

Opening a window

JuChromExplorer.explore — Function
explore(data; kwargs...)
explore(["Sample A" => data_a, "Sample B" => data_b]; kwargs...)
explore([(data=data_a, name="Sample A", color=:navy), data_b]; kwargs...)
explore(; kwargs...)

Open a GLMakie explorer for prepared JuChrom scan series or matrices, an ordered vector of runs, or no initial data. Names are optional; unnamed runs receive Run 1, Run 2, etc. Duplicate names get a suffix. ←/→ cycle through the runs; Unmodified ↑/↓ remain unassigned. Delete/Backspace removes the active run from the window. With no runs loaded, the same three panels are shown without data; removing the last run restores this empty layout.

All TICs are overlaid by default; the active run is in front and inactive traces use 25% opacity. overlay=false shows only the active trace; inactive_alpha adjusts the inactive opacity multiplier. TICs retain their original intensity scale. The title identifies the active run and its position. Single-data calls keep the supplied title / axis.title, defaulting to "Chromatogram" so ion hover cannot add/remove the title row. TIC limits and drag-zoom history are shared.

The first run establishes the display units unless retentionunit / intensityunit are supplied. Every run must have compatible units on both shared axes. Seconds and minutes are converted; unitful and unitless data cannot be mixed. Units cannot distinguish different unitless scales: the caller must align their meaning, e.g. Kováts indices versus other indices, before overlaying them.

Hover previews the active run's spectrum. A/S + left-click or drag adds/subtracts scans; repeating the same gesture erases marks. C clears the active selection. The result is max(0, mean(added) - mean(subtracted)), matching exact m/z values. Both spectra display a base peak of 100% without modifying input data. Each run retains its own selections, preview, manual spectrum limits, and zoom histories.

Hover near an ion's m/z in the middle spectrum to preview its exact-match XIC across runs. X + left-click toggles individual ions; C in that panel clears all. One selected ion compares loaded runs using run colors. Multiple selected ions show only the focused run, with stable ion colors from tic.palette; left/right navigation retains the selection. Selected MS markers match their XIC colors. After the first selection, hovering over an unselected ion adds its focused-run XIC temporarily, using the next ion palette color. One selected plus one hovered ion temporarily enters multi-ion mode; leaving the ion restores the single-ion run comparison. Hovering over a selected ion does not duplicate it. All XICs are solid. TICs are hidden while XICs are displayed; xic.tic_alpha can opt into background TICs (0 by default). XICs use original intensities. Automatic Y limits fit the selected/previewed ion across compatible runs, or all selected and hovered ions in the focused run in multi-ion mode, from the minimum to the maximum plus 5% headroom. Manual Y limits persist while ions remain selected, including across navigation and mode changes. Left Shift + R resumes fitting. Clearing the last ion restores the prior TIC Y scale and clears manual XIC limits, so the next selection starts automatically. Retention zoom history is shared across TIC/XIC transitions: double-click can undo zooms made before ion selection. Saved Y limits are restored only within the same signal context. The retention view stays fixed when changing modes. Missing ions contribute zero; incompatible m/z units are skipped. Multi-ion mode stays empty for a focused run without compatible MS data, retaining the selection. The middle spectrum always uses original data. xic styles XIC lines and ion the selected m/z markers, whose colors are managed. The moving m/z selector is solid and shares the TIC selector's hover style.

The upper panel has matching vertical and horizontal hover lines: the vertical line snaps to a scan, while the horizontal line follows the pointer intensity. Left-drag replaces them with four solid guides and zooms on release; double-click undoes one drag zoom; Escape cancels a drag. Left Shift + ↑/↓ changes only the upper Y limit in the panel under the mouse, in 10% steps (holding an arrow repeats): ↑ makes peaks taller by narrowing the Y range; ↓ makes them shorter by widening it. Left Shift + R resets the TIC upper bound to automatic fitting, or a spectrum to its configured upper bound (110% by default, including label headroom above the 100% base peak). Spectrum zoom-out stops at that configured default; TIC scaling has no ceiling. Lower Y and X limits stay fixed. Right Shift is reserved for a future secondary Y axis and currently has no effect. Wheel zoom, Ctrl-click limit resets, and right-button panning are disabled in all panels. Ordinary Makie xlims! / ylims! remain available. figure, axis, spectrum_axis, result_axis, and screen configure their Makie objects. All panels reserve a fixed Y tick-label width to prevent layout jitter while scaling; override yticklabelspace in the corresponding axis options. NamedTuple style groups tic, hover, zoom, spectrum, selection, subtraction, and result_spectrum override matching Theme(JuChromExplorer=...) defaults per attribute. Extra keywords are forwarded to JuChrom.tictrace!. tic.palette supplies a nonempty vector or tuple of colors, cycling for automatic assignments (Makie's Wong palette by default). A run NamedTuple requires data and accepts optional name and color. Color precedence is per-run color, then tic.color, then the palette. Explicit colors do not consume palette entries; navigation and removal never reassign colors. Later additions continue the sequence. The palette is fixed when the window opens. Left Shift + 1–9 (including the numeric keypad) recolor the active run's left-axis TIC using the corresponding palette entry; keys beyond the palette length do nothing. Left Shift + 0 restores its original color. Right Shift + 0–9 is reserved for a future secondary Y axis; bare digits and chords holding both Shift keys do nothing. These shortcuts also update XICs and markers that use run colors, preserving separate ion colors. H shows numbered color swatches. Save/load preserves both the override and reset color.

importer=callback enables file/directory drops. The callback receives an absolute path and returns prepared data, name => data, a run NamedTuple, or a collection of these. Without an explicit keyword, default_importer loads the optional personal configuration. importer=nothing disables data imports and bypasses that configuration. See loadpaths! for naming, validation, failure handling and progress.

Cmd+S (macOS) / Ctrl+S saves the session as JLD2; add Shift for Save As. Cmd+O / Ctrl+O replaces the current window's contents with a saved session. Session files can also be dropped into the explorer, including with importer=nothing. The first save asks for a filename; later saves reuse it. session_compression=:none is the default; :deflate and :zstd enable lossless compression. session_dialog(action, path) can replace the native file picker; see load_session.

JuChromExplorer.ExplorerSession — Type
ExplorerSession

A window containing an ordered collection of prepared runs. runs and active_index describe the collection; use add_run!, remove_run!, activate_run! and next_run! to change it. Each run has a stable id and an assigned TIC color and initial original_color, stored separately from its original data. Left Shift + 1–9 select a color from the window's fixed tic.palette for the active run's left-axis TIC; unavailable slots do nothing. Left Shift + 0 restores its original color. Right Shift is reserved for a future secondary Y axis.

series and trace refer to the active run and are nothing in an empty window. The original input, including matrix variances, is retained without copying. figure, axis, screen, hovered_scan, hover_line, hover_horizontal_line, and zoom belong to the shared TIC view. The vertical hover_line snaps to a scan; hover_horizontal_line follows the pointer intensity. The upper header shows the run/mode title, scan, retention, and TIC intensity together on one left-aligned line, including in XIC mode. Ion intensities appear left-aligned above the middle spectrum. All readouts use display units; FID data use the same upper header with their direct detector intensity. Press H to toggle keyboard/mouse help; H or Escape closes it. Help pauses plot interactions without changing the current selection or view. Close the window with Shift+Q (either Shift key) or close(session.screen).

spectrum_axis, spectrum_trace, spectrum_scan, spectrum_zoom, selection, selected_scans, subtracted_scans, result_axis, result_trace, result_spectrum, and result_zoom refer to the active run's spectrum panels. They are nothing for an empty window or a run without mass spectra. Empty windows show blank chromatogram, mass-spectrum, and mean-spectrum-difference panels. Selection, last preview, manual spectrum limits, and spectrum zoom histories survive navigation. Treat the collection and derived index observables as read-only.

hovered_ion[] is the temporary XIC target or nothing. pinned_ions[] is a collection of selected targets with mz and unit fields, shared across runs. run.xic.pinned_trace combines that run's selected XICs with NaN separators and per-point colors; run.xic.pinned_mzs gives their order. run.xic.preview_trace holds the temporary XIC, also alongside one or more pinned ions in the focused run. Both plots are nothing for FID data.

importer is the resolved callback or nothing. importing[] and import_status[] report loading progress. import_errors contains the failed paths, exceptions, and backtraces from the latest import operation.

session_path is the last saved/opened JLD2 filename or nothing. session_status[] and session_error report keyboard save/open operations. save_session, load_session, and load_session! preserve data and working views.

JuChromExplorer.add_run! — Function
add_run!(session, [name =>] data; activate=true)
add_run!(session, (data=series, name="Sample", color=:navy); activate=true)

Append prepared data after checking axis units. Compatible units are converted to the window's display units; incompatible or unitful/unitless mixtures are rejected before inserting the run. Returns its stable ID. The current retention view and manual/zoomed Y limits are preserved unless the window was empty. Automatic Y limits adapt to the added data. This does not read files or run an importer. In a NamedTuple, only data is required. An optional color overrides the window's TIC color and palette; nothing uses the normal fallback. Explicit colors do not consume palette entries. Existing runs retain their colors.

Importing files

See Importing files for callback return types and configuration.

JuChromExplorer.default_importer — Function
default_importer([path])

Load an optional Julia configuration file defining importer(path). By default, look in joinpath(first(DEPOT_PATH), "config", "JuChromExplorer.jl"), normally ~/.julia/config/JuChromExplorer.jl. A missing file means no importer (nothing). The file is evaluated in a separate module for each new window, so its imports and helper definitions do not overwrite Main or JuChromExplorer. Relative include calls in the configuration resolve beside that file. Invalid configurations raise an error before a window is opened.

explore(importer=my_importer) bypasses this file; explore(importer=nothing) bypasses it and disables data-file drops. Saved explorer sessions can still be dropped to reopen them. The package never creates the configuration.

JuChromExplorer.loadpaths! — Function
loadpaths!(session, path_or_paths) -> Vector{Int}

Import files/directories with this window's importer, using the same logic as drag-and-drop. Returns the stable IDs of successfully inserted runs. Each path is atomic: all its returned runs are validated before insertion, and a plotting error rolls back its additions. A failed path is logged and does not stop later paths. Inspect session.import_errors for failures from the latest import operation.

The importer receives an absolute path and may return prepared data, name => data, (data=series, name="Sample", color=:navy) (name and color optional), or an ordered vector/tuple of these. An empty collection skips the path. Invalid colors reject the whole path, and failed imports do not consume palette entries. Missing names use the file/directory stem (plus a position for multiple outputs). Existing names are disambiguated with a numeric suffix. The first run from each successful path becomes active. The retention view and manual/zoomed Y limits are preserved; automatic TIC Y limits adapt to added data. An empty window initializes its view.

This function waits for the import to finish. Drops are queued in a cooperative task; additional drops join that queue. Callbacks run serially on the GUI thread, so CPU-heavy processing without yielding can temporarily pause interaction. An explicit call while another import is running raises ArgumentError.

Saving and reopening sessions

See Saving sessions for file dialogs, compression, and compatibility.

JuChromExplorer.save_session — Function
save_session(session[, path]; compression=session.options.session_compression, save_as=false)

Save all loaded run data and the explorer's selections, extracted spectra, styles, axis limits, and zoom histories in one JLD2 file. No original input files are needed to reopen it. Compression defaults to :none; :deflate and :zstd are optional.

Without a path, reuse session.session_path, or open a native save dialog on the first save. save_as=true always opens the dialog. Return the absolute saved path, or nothing on cancellation. An explicit path is used exactly as supplied; native save dialogs append .jld2 if necessary. A successful save remembers its path and compression choice. Writes replace the destination only after the file is complete.

The session format is versioned to detect incompatible files; long-term session compatibility is not promised. GUI objects and importer/dialog callbacks are rebuilt on load. Do not save while an import is running or a mouse gesture is in progress.

JuChromExplorer.load_session — Function
load_session([path]; importer=default_importer(), screen=(;), figure=(;),
             session_compression=nothing, session_dialog=...)

Open a JLD2 session in a new explorer window. With no path, show the native open dialog; cancellation returns nothing. Restore embedded runs (including metadata and variances), selections and extracted spectra, colors, display settings, axis limits and zoom histories. To replace an existing window's contents, use load_session!; the Open shortcut and session-file drops use that form.

screen and figure override window settings. session_compression overrides the saved choice for subsequent saves; otherwise the choice stored in the file is used. The importer is resolved for the new window, not stored as executable code in the file. session_dialog(action, suggested_path) can supply an alternative file picker; return a path, nothing, or an empty string to cancel. The same keyword is accepted by explore. Incompatible format versions are rejected before opening a window.

source
JuChromExplorer.load_session! — Function
load_session!(session[, path]; session_compression=nothing)

Replace the contents of an existing explorer window with a saved JLD2 session. Return the same ExplorerSession, retaining its native window, importer, and file-dialog callback. With no path, show the native open dialog; cancellation returns nothing. A failed load leaves the previous contents available.

Loaded data and views replace the current work, so save it first if needed. Finish any import or mouse gesture before loading. session_compression can override the saved choice for subsequent saves.
